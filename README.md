## Призначення

Програма аналізує дані студентів: виводить список, визначає унікальні групи, обчислює середній бал і знаходить найкращого студента. Також реалізовано фільтрацію за балом, рейтинг, групування, підрахунок студентів у групах і пошук за ID.

Вхідні дані задано у функції `get_students()` у файлі `src/data_processor/data.py`. Кожен запис містить ID, ім’я, прізвище, групу та середній бал.

## Структура проєкту

```text
Lab_02_variant_1/
├── pyproject.toml
├── README.md
├── .gitignore
├── src/
│   └── data_processor/
│       ├── __init__.py
│       ├── data.py
│       ├── processors.py
│       ├── analytics.py
│       ├── decorators.py
│       ├── main.py
│       └── benchmark.py
├── tests/
│   └── test_processing.py
└── report/
    └── Report_lab_02.pdf
```

- `data.py` — вхідні дані студентів.
- `processors.py` — пошук, фільтрація, сортування та групування.
- `analytics.py` — обчислення середнього бала, визначення найкращого студента та створення порогового фільтра.
- `decorators.py` — декоратор вимірювання часу.
- `main.py` — запуск програми та виведення результатів.
- `benchmark.py` — порівняння швидкості пошуку у списку та словнику.
- `test_processing.py` — автоматизовані тести.

## Встановлення

Команди виконуються у Windows PowerShell із кореневого каталогу проєкту.

Створення віртуального середовища:

```powershell
& "C:\Program Files\Python311\python.exe" -m venv .venv
```

Встановлення пакета та залежностей для тестування:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
```

## Запуск програми

```powershell
.\.venv\Scripts\python.exe -m data_processor.main
```

За замовчуванням програма відбирає студентів із балом вище 85 та шукає студента з ID 3.

Для зміни порога та ID:

```powershell
.\.venv\Scripts\python.exe -m data_processor.main --threshold 90 --student-id 2
```

## Порівняння швидкості пошуку

```powershell
.\.venv\Scripts\python.exe -m data_processor.benchmark
```

Пошук у списку та словнику порівнюється на наборах із 1 000, 10 000 і 100 000 записів. Окремо вимірюється час створення словникового індексу. Результати виводяться в терміналі.

## Тестування

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тести перевіряють обчислення, фільтрацію, сортування, пошук, обробку порожнього набору та повторних ID.
