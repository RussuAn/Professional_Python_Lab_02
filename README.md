## Встановлення у Windows PowerShell
Відкрийте термінал у каталозі з pyproject.toml.
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
python -m data_processor.main
python -m data_processor.main --threshold 90 --student-id 2
python -m data_processor.benchmark
python -m pytest -q
```
Якщо активація недоступна, замініть `python` на `.\.venv\Scripts\python.exe`.
Для Linux: `python3 -m venv .venv`, `source .venv/bin/activate`, далі ті самі команди Python.

## Вхідні дані та операції
У data.py задано шість вигаданих студентів; дані можна змінювати у get_students().
Поля першої роботи збережено: first_name, last_name, group, average_grade.
Додано унікальний id. Бал задається числом від 0 до 100.
Це окремий модуль аналізу готового набору, як у прикладі методички Lab 02.
Програма виводить список, унікальні групи, загальний середній бал, найкращого
студента, вибірку строго вище порога, рейтинг, групування, кількість у групах
і пошук за ID. Параметри --threshold і --student-id задає користувач.
Очікуваний середній бал: 84.67; найбільший: 95; у кожній групі по 2 студенти.

## Модулі
- data.py: список записів і tuple назв полів.
- processors.py: comprehensions, індекс, пошук, універсальні filter/sort,
  defaultdict та Counter.
- analytics.py: агрегація, lambda, *args, **kwargs і closure.
- decorators.py: вимірювання часу з functools.wraps.
- main.py: послідовне виконання та виведення таблиць.
- benchmark.py: порівняння list і dict на 1 000, 10 000, 100 000 записів.

## Особливі випадки
Для порожнього набору середнє та найкращий студент дорівнюють None.
При рівних максимумах обирається перший запис. Сортування стабільне,
не змінює початковий список. Повторні ID відхиляються; однакові прізвища
дозволені. Згенеровані набори benchmark мають унікальні ID.

## Складність і benchmark
Лінійний пошук: O(n); побудова індексу: O(n) у середньому;
пошук у dict: O(1) у середньому, O(n) у найгіршому випадку;
сортування: O(n log n) у найгіршому випадку.
Benchmark шукає останній ID. Наведено медіану 5 серій: по 100 пошуків
для list і по 100 000 для dict, результат поділено на кількість викликів.
Побудова індексу вимірюється окремо й не входить у час пошуку.
Це порівняння повторного пошуку після індексування, а не одноразового запиту.
Результати залежать від комп'ютера. Таблиця виводиться в терміналі.
Вимірювання враховує накладні витрати виклику lambda.
